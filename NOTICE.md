## No vendored source

No upstream source code is copied into this repository. `manimx/` calls and
monkey-patches the Manim package installed at runtime by `bin/setup`; nothing
from Manim is redistributed here.

## Derived artifacts

Two things in this repository derive from upstream projects. Both upstreams are
MIT-licensed.

### `api/` — generated by reflection

`bin/mx api-dump` walks the *installed* packages and emits public symbol names,
signatures, and the **first line** of each docstring. Running it on your own
machine reproduces the directory from your own installation.

## Runtime dependencies

Manim itself is **not** distributed here — `bin/setup` installs it from PyPI
into a local virtualenv that is gitignored.

Worth knowing: the PyAV wheel installed into `.venv/` bundles an FFmpeg build
that includes GPL-licensed encoders (`libx264`, `libx265`). That wheel is a
runtime dependency fetched by the user from PyPI and is not redistributed by
this repository, so its terms do not reach this repository's source. If *you*
redistribute a built artifact that embeds those binaries, the GPL terms apply
to you.

A scan of both virtualenvs (77 distributions) found no GPL or AGPL packages in
the Python dependency graph. The only weak-copyleft entries are `pycairo`
(LGPL-2.1-only OR MPL-1.1) and `tqdm` (MPL-2.0 AND MIT); neither is vendored.
